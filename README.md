# ES-DOS
I created an MS‑DOS analog for ESP32 — ES‑DOS. This operating system can scan Wi‑Fi networks, control LEDs, and reboot the board via simple text commands. It runs in the Serial Monitor and fits into the ESP32’s memory with room to spare.

How to install? 
To install the project, go to the Releases tab. There, select the desired version and download the ZIP file. After downloading, extract the archive, navigate to the folder, and open the .ino file in the Arduino IDE
